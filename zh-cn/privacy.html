隐私政策

政策更新日期：2026 年 10 月 7 日

Orivela Works（以下简称“我们”）在此说明 FrameCatalog 和本网站如何处理信息。

FrameCatalog 将视频库信息保存在您的电脑上。应用没有自动将登记的视频或视频库信息上传到我们服务器的功能。

1. 应用处理的信息和用途

为了添加、显示、搜索、播放、编辑和备份视频库，应用会处理您选择的视频及下列信息：

  • 文件名、存储位置、大小、时长、分辨率、编码格式及视频元数据中的拍摄时间等
  • 由视频生成的缩略图、预览和文件识别信息
  • 您填写的标题、演员、提供方、别名、备注、分类、标签和评分等
  • 应用设置及 Microsoft Store 购买许可信息

视频、文件名、位置及填写的内容可能包含可识别个人的信息。请仅登记所需内容，并妥善处理他人的信息。

2. 存储与备份

视频库数据库、缩略图、预览和设置保存在电脑上的应用数据文件夹中。原视频保留在您指定的位置。

备份保存到您选择的位置，包含视频库信息和图片，原视频文件不包含在内。若选择共享文件夹或云同步文件夹，数据可能按该服务的设置被他人访问或同步到电脑之外。

3. Microsoft Store 与外部服务

解除数量限制的付费升级通过 Microsoft Store 获取商品信息、处理购买和验证许可。支付与 Microsoft 帐户由 Microsoft 处理，FrameCatalog 不获取您的银行卡号码或 Microsoft 帐户密码。

应用使用 Microsoft Edge WebView2 显示界面。有关 Microsoft Store、Windows、WebView2 等服务处理的使用和诊断数据，请参阅相应设置及 Microsoft 隐私声明。

4. 广告与访问分析

FrameCatalog 和本网站未嵌入我们自己的广告投放或行为追踪工具。网站托管服务商可能为提供页面及维护安全而处理 IP 地址、访问时间等连接信息。

5. 支持咨询

您通过电子邮件联系我们时，我们使用您的电子邮件地址、姓名（如有提供）、正文和附件等来回复和调查问题。我们通过 Gmail 收发邮件。有关 Google 的处理方式，请参阅 Google 隐私权政策。

我们在处理咨询所需的期间内保留这些信息，并删除不再需要的信息。我们不会出售这些信息，也不会将其用于上述目的以外的广告。除非法律要求，我们不会向处理咨询所不需要的第三方提供这些信息。

6. 管理与删除信息

您可以在应用中移除视频库条目。原视频和已创建的备份由您自行管理和删除。购买记录由 Microsoft Store 管理。

如需查阅、更正或删除您通过电子邮件提供的信息，请通过下方地址联系我们。必要时，我们可能核实您的身份。

7. 政策变更

应用功能或服务变化时，我们可能更新本政策。更新内容和日期会在本页公布。
