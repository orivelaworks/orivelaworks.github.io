主要功能

管理电脑里的视频

选择文件或文件夹，批量添加 MP4、MOV、MKV、AVI 等格式的视频。原文件保留在原处，软件会自动读取时长和分辨率等信息。

在列表中快速找到视频

浏览缩略图，快速查看视频内容。把鼠标移到缩略图上即可播放短预览，无需逐个打开视频。 还可自由选择视频中的时间点来制作缩略图。

用自定义字段整理

除了标签和评分，还能创建类型等适合自己收藏的字段。可为演员和提供方登记别名，将不同写法归到同一条记录。 还可以按演员或标签统计视频数量。

筛选想看的视频

将标签的 AND／OR 搜索与演员、拍摄日期、分辨率等条件组合起来。常用筛选条件可以保存，下次直接调用。

查看详细功能

添加视频

选择视频文件或整个文件夹批量添加，也可以包含子文件夹。原视频保留在原处，软件会读取时长和分辨率等信息，并生成缩略图。

如果视频元数据包含拍摄时间，软件可以读取日期和时间。批量添加后，可在结果中查看未能读取的文件。

预览视频

将鼠标移到缩略图上即可播放无声短预览。想看完整视频时，可用平时使用的播放器打开原文件。

可以更换自动生成的缩略图。输入时间或移动滑块，查看不同时间点的画面，再选择想用的那一帧。

管理视频库

使用标签和五星评分，也可创建文本、日期、选项等自定义字段。需要给多个视频填写相同信息时，可以批量编辑。

集中管理演员和提供方的别名。可为演员单独评分和设置收藏排名，按演员分组浏览，还可以逐个视频记录同一演员的服装等信息。

查看视频库统计

可统计整个视频库，也可只统计筛选结果。查看视频数量、演员人数、总时长和原视频总大小。点击演员或标签的统计明细，即可打开对应的视频列表。

搜索与筛选

可按文件名和已填写的信息搜索，组合标签、评分、拍摄日期范围、分辨率、时长和文件夹等条件。标签可选全部匹配（AND）或任意匹配（OR）。

用演员姓名或别名查找相关视频。可以为常用筛选条件命名并保存，之后直接调用。

备份与恢复

可将视频库记录、自定义字段、缩略图、预览和显示设置一起备份，并在需要时恢复。原视频文件请另行备份。

系统要求

需要 Windows 10 或 Windows 11 的 64 位（x64）电脑。H.265（HEVC）视频需要 Windows 的 HEVC 支持，Microsoft Store 的 HEVC 扩展可能需要付费。建议先用免费版确认手头的视频能否添加并生成预览。

常见问题

添加视频时需要移动原文件吗？

添加视频时，FrameCatalog 会记录原文件的位置。移除视频库条目后，原文件仍保留在原处。

如何完整播放视频？

点击播放按钮后，会使用电脑上关联的视频播放器打开原文件。
