批量添加与编辑

批量添加视频并自动生成缩略图，读取时长和分辨率等信息。可批量编辑字段，并按指定时间点更换缩略图。

按演员分组浏览

记录演员的别名、评分和收藏排名，还可为同一演员在不同视频中记录发型、服装等信息。

保存和管理筛选条件

按评分、标签、演员、拍摄日期及文件夹等组合筛选。常用条件可保存并通过箭头或拖动排序。

统计与备份

查看视频数量、总时长、文件大小和分类统计。可备份视频库信息、缩略图及预览，原视频文件需另行保管。

系统要求

需要 Windows 10 或 Windows 11 的 64 位（x64）电脑。H.265（HEVC）视频需要 Windows 的 HEVC 支持，Microsoft Store 的 HEVC 扩展可能需要付费。建议先用免费版确认手头的视频能否添加并生成预览。

常见问题

添加视频时需要移动原文件吗？

添加视频时，FrameCatalog 会记录原文件的位置。移除视频库条目后，原文件仍保留在原处。

如何完整播放视频？

点击播放按钮后，会使用电脑上关联的视频播放器打开原文件。
